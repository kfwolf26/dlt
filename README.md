# 大乐透过滤工具（狼奖多多）

一款基于 Python + Tkinter 开发的中国体育彩票「超级大乐透」分析与预测桌面工具，集号码过滤、历史查询、走势图、预测模型、定位定胆于一体，帮助彩民进行号码分析与选号参考。

> ⚠️ 本工具仅供学习研究使用，彩票中奖为随机事件，请理性购彩，勿沉迷。

## 功能特性

工具采用多标签页（Tab）布局，主要包含五大模块：

### 🎯 过滤工具
对大乐透所有组合（前区 1-35 选 5，后区 1-12 选 2）按多维度条件进行缩水过滤：
- 前区定位：5 个位置，每位置可指定候选号
- 前区杀号 / 后区杀号
- 奇偶比、大小比、三区比
- 和值范围、跨度范围
- 连号类型（无连号 / 2 连 / 3 连 / 4 连+）
- 其他高级过滤条件

### 📊 历史查询
管理并查询大乐透历史开奖记录，自动计算每期的：
- 和值、跨度
- 奇偶比、大小比、三区比
- 连号类型
支持增删改查与按期号检索。

### 📈 走势图
一键打开中彩网官方走势图：
- 大乐透走势图
- 双色球走势图
- 福彩 3D 走势图

### 🔮 预测模型
基于历史数据生成下期预测号码，并提供：
- 多组预测号码生成
- 命中奖级判定（一至九等奖，官方 9 级制）
- 预测结果保存与回测
- 可配置的预测参数

### 🎯 定位定胆
基于历史统计的定胆辅助工具，包含四个子标签页：
- 前区不定位三胆
- 前区定位三胆（可选位置 1-5）
- 后区定三胆
- 前区杀三码
支持自定义统计期数，并由虚拟"预测师"输出结果。

## 项目结构

```
dlt/
├── main.py                     # 程序入口
├── modules/                    # 功能模块
│   ├── filter_tool.py          # 过滤工具
│   ├── history_query.py        # 历史查询
│   ├── trend_chart.py          # 走势图
│   ├── prediction_model.py     # 预测模型
│   └── location_dingdan.py     # 定位定胆
├── utils/                      # 工具类
│   └── history_manager.py      # 历史数据管理（单例）
├── history.json                # 历史开奖数据
├── prediction_data.json        # 预测数据
├── prediction_settings.json    # 预测参数配置
└── saved_predictions.json      # 已保存的预测记录
```

## 环境要求

- Python 3.8 及以上
- 仅使用 Python 标准库（Tkinter、json、os、random、threading、itertools 等），无需安装任何第三方依赖

## 快速开始

1. **克隆仓库**

   ```bash
   git clone https://github.com/你的用户名/仓库名.git
   cd 仓库名
   ```

2. **运行程序**

   ```bash
   python main.py
   ```

3. 程序启动后将显示主窗口，点击顶部标签页切换各功能模块即可。

## 数据文件说明

| 文件 | 说明 |
| --- | --- |
| `history.json` | 存储大乐透历史开奖记录，支持在「历史查询」中维护 |
| `prediction_data.json` | 存储预测模型生成的预测数据 |
| `prediction_settings.json` | 存储预测模型的可配置参数 |
| `saved_predictions.json` | 存储已保存的预测记录，用于回测对比 |

> 首次使用时若数据文件不存在，程序会自动创建空数据结构。

## 使用建议

- 首次使用建议先在「历史查询」中导入或手动录入历史开奖数据，预测与定胆功能依赖历史数据。
- 「过滤工具」条件越多，结果越精简，但可能过滤掉中奖组合，请合理设置。
- 「预测模型」生成过程支持进度提示，大数据量生成请耐心等待。
- 所有界面布局采用百分比自适应，可在不同分辨率下正常显示。

## 技术说明

- 图形界面基于 Python 内置 **Tkinter**，无需额外安装 GUI 库。
- 历史数据管理采用 **单例模式**（`HistoryManager`），保证全局数据一致性。
- 预测模型采用 **多线程** 生成，避免阻塞 UI。
- 大乐透奖级判定遵循官方 9 级制规则。
