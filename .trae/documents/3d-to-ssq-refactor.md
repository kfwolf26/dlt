# 福彩3D → 双色球 改造实施计划

## Context（背景）

当前项目位于 `d:/ai/ssq`，目录名为 ssq（双色球）但实际代码是福彩3D过滤工具。3D 规则是从 000-999 中选 3 位数（百/十/个位各 0-9），共 1000 注。用户希望将整个工具完全改造为符合双色球规则：红球 6 个（1-33 不重复）+ 蓝球 1 个（1-16），总注数 C(33,6)×16 = 17,721,088。

用户确认：
- **完全替换**为双色球，不保留 3D
- 过滤功能仅包含**基础过滤**：红球定位/杀号/胆码、蓝球杀号/定胆、和值、跨度、奇偶比、大小比、三区比、连号
- 历史 3D 数据直接**清空覆盖**
- 预测模型目标：**红球杀号（不定位）+ 蓝球定胆**

---

## 双色球规则核心参数

| 项 | 范围 | 说明 |
|---|---|---|
| 红球 | 1-33 选 6（不重复） | 升序排列 |
| 蓝球 | 1-16 选 1 | 与红球独立 |
| 红球和值 | 21-183 | 6 个红球之和 |
| 红球跨度 | 5-32 | max - min |
| 奇偶比 | 6:0 / 5:1 / 4:2 / 3:3 / 2:4 / 1:5 / 0:6 | 红球 |
| 大小比 | 6:0 / 5:1 / 4:2 / 3:3 / 2:4 / 1:5 / 0:6 | 小=1-16，大=17-33 |
| 三区比 | 1区(1-11) : 2区(12-22) : 3区(23-33) | 红球 |
| 连号 | 无 / 2连 / 3连 / 4连+ / 任意 | 相邻数字之差=1 |

## 模块改造方案

### 1. `utils/history_manager.py` — 数据结构兼容
原结构保持（issue/number/date/sum/span/type），但 `number` 改为 `"r1,r2,r3,r4,r5,r6|b"` 格式（如 `"1,5,12,18,25,33|7"`）。增加 `red`（list[6]）、`blue`（int）、`odd_even`、`big_small`、`zones`、`consecutive` 字段。单例模式保持不变。

### 2. `modules/history_query.py` — 历史查询改造
- **录入**：期号、6 个红球输入框（1-33 互异校验）、1 个蓝球输入框（1-16）、日期
- **批量导入格式**：`期号,r1,r2,r3,r4,r5,r6,蓝球,日期`（每行一条）
- **Treeview 列**：期号 / 红球 / 蓝球 / 日期 / 和值 / 跨度 / 奇偶 / 大小 / 三区 / 连号
- **统计**：红球频率（1-33）、蓝球频率（1-16）、和值分布、跨度分布、奇偶分布、大小分布、三区分布、热号

### 3. `modules/filter_tool.py` — 完全重写为双色球过滤
**生成策略**（性能关键）：
- 用 `itertools.combinations(range(1,34), 6)` 生成 1,107,568 个红球组合
- 先应用红球过滤条件（杀号、胆码、和值、跨度、奇偶、大小、三区、连号、定位）
- 再笛卡尔积 1-16 蓝球，应用蓝球过滤
- 用集合与短路判断加速

**过滤条件（按 UI 顺序）**：
1. 红球定位（位置 1-6，每个位置勾选 1-33）
2. 红球杀号（勾选 1-33 中排除的号码）
3. 红球胆码（勾选 1-33 中必含的号码）
4. 蓝球杀号（勾选 1-16 排除）
5. 蓝球定胆（勾选 1-16 必含，单选式）
6. 和值（21-183 多选）
7. 跨度（5-32 多选）
8. 奇偶比（7 种多选）
9. 大小比（7 种多选）
10. 三区比（常见 28 种多选，简化为下拉勾选）
11. 连号（单选：不过滤 / 必须无连号 / 必须有连号 / 必须有 2 连 / 必须有 3 连+）
12. 号码组过滤（最多 5 组，每组勾选号码 + 指定出现次数 0-6）

每个条件都支持"包含选中/排除选中"模式（沿用原 `_add_mode_checkgroup` 工具方法）。

**结果展示**：`"01 05 12 18 25 33 + 07"` 格式，每行 5 注。

### 4. `modules/prediction_model.py` — 红球杀号 + 蓝球定胆
保持原"预测者+连续命中"机制，但改造预测目标：
- 每个预测者每期生成：
  - `red_kill`: 从 1-33 中随机杀 N 个号码（默认 8 个，可配置）
  - `blue`: 从 1-16 中随机预测 1 个蓝球
- **杀号计算**：取连续命中 ≥ min_streak 期的预测者，将其当期红球杀号合并去重 → 得到红球总杀号集 → 红球剩余号码 = {1..33} - 杀号集
- **蓝球定胆**：取连续命中 ≥ min_streak 期的预测者当期蓝球预测，统计频率，列出推荐蓝球
- 命中判定：
  - 红球：当期 6 个红球 **全部不在**预测者的杀号集中 → 该预测者命中
  - 蓝球：当期蓝球 == 预测者蓝球 → 命中
- 三栏展示改为：**红球杀号结果** / **红球剩余号码** / **蓝球定胆结果**

### 5. `modules/location_dingdan.py` — 红球定胆 + 蓝球定胆
保持 10 个虚拟预测者展示形式，4 个子 tab 改为：
- **红球不定位三胆**：每预测者出 3 个红球胆码（1-33），命中=任一胆码在 6 红球中
- **红球定位三胆（位置 1/2/3/4/5/6）**：每预测者出 3 个候选号给指定位置，命中=该位置红球 ∈ 候选
- **蓝球定三胆**：每预测者出 3 个蓝球候选（1-16），命中=蓝球 ∈ 候选
- **红球杀三码**：每预测者出 3 个红球杀号，命中=3 个杀号均不在 6 红球中

### 6. `modules/trend_chart.py` — 走势图链接
- 主按钮改为「双色球走势图」，链接 `https://chart.zhcw.com/zst/ssq.html` 或类似官方源
- 保留 3D/排列3/排列5 作为辅助按钮

### 7. `main.py` — 标题与窗口
- `self.root.title("双色球过滤工具（狼奖多多）")`
- 5 个 tab 保留，文案中"3D"改为"双色球"

## 验证方法

1. **启动验证**：在 `d:\ai\ssq` 下运行 `python main.py`，窗口标题为"双色球过滤工具（狼奖多多）"，5 个 tab 正常显示
2. **历史查询**：手动添加 1 条双色球记录（如 `2026170,1,5,12,18,25,33,7,2026-06-29`），Treeview 显示正确，统计页能看到红蓝球频率
3. **过滤工具**：
   - 不设任何条件 → 输出 17,721,088 注（或仅显示总数）
   - 红球胆码设 3 个 → 数量大幅缩减
   - 蓝球定胆设 1 个 → 数量 ÷ 16
   - 和值+奇偶+大小组合 → 验证结果合理
4. **预测模型**：先录入 30 期历史 → 生成预测数据 → 计算杀号 → 红球剩余号码数 = 33 - 杀号数
5. **定位定胆**：4 个子 tab 都能刷新显示，命中标红
6. **走势图**：点击按钮能在浏览器打开双色球走势图

## 注意事项

- 双色球红球组合数 110 万，遍历需用 `itertools.combinations` 而非全量 17M；蓝球循环 16 次在内层
- 红球号码显示统一两位补零（`01`、`33`），蓝球也补零
- 期号格式沿用 `YYYYNNN`（如 `2026170`），与原 3D 兼容
- 所有 tkinter 变量初始化保持 `BooleanVar` / `IntVar` 模式，沿用原工具方法 `_add_section_title`、`_add_mode_checkgroup`、`_check_all`
- 保留原代码风格：中文按钮带 emoji、白底 Canvas 滚动、`微软雅黑` 字体
